# 複利計算シミュレーター

取得額、現在の評価額、毎月の積立額、現在の年齢、運用年数、年間利回り、課税・非課税を指定し、資産推移や目標達成に必要な積立額を確認できるシミュレーターです。

## 主な機能

- 入力内容に応じたリアルタイム再計算
- 指定した年数後の資産、累計投資額、運用益、年齢の表示
- 取得額と現在の評価額を分けたNISA枠計算
- 現在の年齢、目標年齢、目標金額から必要な月々の積立額を逆算
- 通常資産とDC資産を合算した将来資産シミュレーション
- 資産推移のインタラクティブグラフ
- 1年ごとの詳細表
- スマートフォン対応

課税対象を選択した場合は、運用益に税率20.315%を反映します。
